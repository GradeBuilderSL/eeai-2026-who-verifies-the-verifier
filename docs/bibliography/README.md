# Bibliography

`references.bib` — 557 entries on temporal knowledge in LLMs, agent memory systems, bitemporal data models,
restriction drop / faithfulness, verification and provenance, knowledge conflicts, temporal extraction, and the
2025–2026 frontier. Collected 12 September 2026 for the literature survey behind this talk; the cluster summaries
are in `bibliography-summary.ru.md` (Russian — the working language of the survey).

**The honest header, verbatim from the survey** (translation below):

> Всего: 557; сверено: 537; не сверено: 20.

> 557 записей каталога не означают 557 проверенных Astra работ; уровни проверки в реестре 21.

*Total: 557; checked against the primary source: 537; not checked: 20.* — and — *557 catalogue entries do not
mean 557 works verified by Astra; the verification levels are in register 21.* Entries marked «НЕ СВЕРЕНО» in the
summary were never confirmed against a primary source and were not used for any claim in the talk. The talk
itself cites a handful of these works (the related-work list in the root README); the rest is the map we read
before deciding what to measure.
